# v0.2 — Evidence and pedagogy architecture

v0.2 establishes the reusable evidence and teaching architecture for
Plasmid Eco-Evo.

Included:
- two-axis claim ontology: layer × status
- stable claim IDs and claim validation
- evidence-state and comparison conventions
- shared palette and accessibility conventions
- reading paths
- contributor checklist
- Predict → Evidence → Diagnose → Reconstruct → Transfer pedagogy
- worked applications of that pedagogy
- deterministic figure provenance
- the participant-material policy and the gitignore guard under it
- the public-correctness and bibliography corrections incorporated before
  release

Explicitly deferred:
- broader claim-scope normalisation
- model provenance and the 59/59 validation redesign
- model/notebook infrastructure
- communications re-audit
- machine-readable knowledge indexes / MCP
- further visual-design work
- a committed bibliography-key checker. Any such checker must enumerate the
  file types it reads and fail visibly on types it does not: during this
  release cycle a scratch checker silently reported three real citations as
  orphans because it did not open `.ipynb`, and a committed checker with the
  same blind spot would have reported clean on a file it never read

A v0.2 tag means this architecture is usable and internally coherent, not
that every planned scientific or tooling improvement is complete.

## What the version numbers in this repository mean

`v0.1` described a repository whose figure did not yet use a shared palette.
Two files still refer to it — `figures/README.md` and
`figures/source/palette.py` — and those references are **deliberate**. They
record which release the pathway figure came from, which is the explanation
for why that one figure does not use the palette module. Removing them would
delete the justification and leave an unexplained exception, so they stay.
